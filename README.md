# Future Architecture — сайт

Next.js 16 + Payload CMS 3 на Postgres (Neon). Три страницы, перенесённые
один в один из исходной вёрстки, и админка для контента и заявок.

| Маршрут  | Страница    |
| -------- | ----------- |
| `/`      | Сообщество  |
| `/forum` | Форум 2026  |
| `/award` | Премия      |
| `/admin` | Админка Payload |

## Запуск локально

```bash
npm install
cp .env.example .env      # и подставить свои значения
npm run dev
```

Первый заход на `/admin` предложит создать администратора.

## Переменные окружения

| Переменная             | Зачем |
| ---------------------- | ----- |
| `DATABASE_URI`         | Строка подключения к Postgres (Neon). |
| `PAYLOAD_SECRET`       | Секрет для подписи сессий. Любая длинная случайная строка. |
| `NEXT_PUBLIC_SITE_URL` | Публичный адрес сайта, нужен для метаданных. |

## Что редактируется через админку

**Контент**

- *Форум — настройки*: дата форума (от неё считается таймер), показ таймера.
- *Премия — настройки*: дедлайн и подпись к нему, показ таймера, жюри
  (список + флаг видимости блока), номинации премии и студенческого конкурса.

**Заявки** — три отдельные папки входящих, по одной на страницу. Формы сайта
пишут туда напрямую; на чтение нужен вход в админку.

Если база недоступна, страницы всё равно отрисуются на значениях по умолчанию —
теми же, что были зашиты в исходной вёрстке.

## Как устроен перенос

Исходные страницы приехали как самораспаковывающиеся бандлы на собственном
рантайме с шаблонным языком (`{{ }}`, `style-hover`, `sc-if`, `sc-for`).
Перенос сделан так:

- **Разметка и инлайн-стили** перенесены дословно.
- **Адаптивность** раньше считалась в JavaScript — стала CSS-переменными с
  медиазапросами (`globals.css`). Значения на каждом брейкпоинте те же, но
  вёрстка больше не зависит от JS.
- **`style-hover` / `style-focus`** превратились в обычные CSS-классы.
- **Анимации** (`fa-motion.js`) — исходный ванильный скрипт без изменений:
  reveal по скроллу, счётчики, бегущие строки, таймеры, параллакс.
- **Состояние страниц** (меню, валидация форм, выбор трека премии) переписано
  на React-хуки один в один с исходной логикой.

Результат сверялся с оригиналом попиксельно: все три страницы совпадают, разница
только в тикающих секундах таймера.
